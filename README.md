# 小狗词书 · Puppy Words

可部署在 GitHub Pages 的通用背词 PWA。独立实现常见的分组学习、释义选择题和错词重测；不包含第三方词书、原项目代码或录音。程序不需要账号、后端、Node 或 npm 安装。

## 上传到 GitHub，然后安装

1. 解压，进入 `puppy-vocab` 文件夹。
2. 在 GitHub 新建仓库，例如 `puppy-vocab`。上传本文件夹里的文件和目录到仓库根目录（`index.html` 在根目录），保留 `vendor` 文件夹。
3. 仓库 Settings → Pages → Build and deployment → Source 选择 Deploy from a branch；Branch 选 `main`，目录 `/ (root)`，保存。
4. 部署完成后打开 GitHub 显示的网址，例如 `https://你的用户名.github.io/puppy-vocab/`。
5. 等页脚显示“程序已缓存 · 可离线背词”。在设置里点“安装 App”，或用浏览器菜单安装。iPhone / iPad 用 Safari 的分享 → 添加到主屏幕。

不要把你的私人词书、阅读器 JSON 备份和学习备份上传到公开仓库。在已经打开的 App 里导入，它们保存在当前浏览器的 IndexedDB 中。

## 词书导入

- `.xlsx`：支持普通、未加密 Excel 工作簿，可选择工作表。不支持旧 `.xls`、宏、公式计算或密码加密文件；公式仅读取文件中已保存的结果。
- UTF-8 `.csv` / `.tsv`：支持双引号、字段中的逗号与换行。
- 小狗阅读器 JSON 备份：阅读器 → 导出备份，本工具 → 导入。可以同时选多份阅读器备份。
- 自定义 JSON：词条数组，例如 `[{"word":"remember","meaning":"记得","group":"1"}]`，或 `{"words":[...]}`。
- 每个文件限制 50 MB，Excel 解压限制 100 MB，每张表最多十万行。选择多个表格时，工作表下拉框决定本次导入哪个表；阅读器备份和 JSON 词条数组则同时汇总。其他工作表再分别导入即可。

表格可以手动映射：单词、中文释义、英文释义、音标、组号、笔记和来源。默认识别常用中文和英文列名。没有列名可以取消“第一行是列名”。有旧版 `random` 或序号列时，可以手动选择按该列数值顺序排序；程序没有内置旧词书，所以必须由你提供相应表格，才能复现旧词序。

## 分组和累加

- 新词书：默认保留文件行序；有组号列按组号聚合，并以组首次出现顺序排列。无组号默认每 20 词一组，可改为 1–100。
- 追加：选择已有词书。仅把本书尚未出现的词加入**新组**，即使原末组不满，也不补进旧组。原组的成员、ID、顺序和学习记录保持不变。
- 去重：忽略首尾空格、英文大小写和弯／直撇号差异；保留复数、时态和短语，不做词形还原，以免合并不同词义。每本书只收录同一个规范词条一次。
- 跨词书：同一个词可属于多本书，但共享词条释义、错误数和已通过状态。修改释义会在所有词书里生效。
- 重复释义：填补空字段；已有释义不同则保留原释义，新增释义存为备选，可在编辑词条中查看和复制。
- 原书分组和阅读生词可以分别建书，也可以把阅读生词追加到原书。追加的阅读词会按设定大小另开组。

## 小狗阅读器兼容

兼容 `puppy-reader-backup` version 1（已检查小狗阅读器 v2 当前备份结构）。默认提取 `study.words` 中手动标记的单词。可勾选包含选中的粗体词，沿用“单个粗体词 / 连续粗体词组”以及排除标记。顺序按单词在故事中首次出现的顺序；多故事同词合并，来源可保留多篇故事名。仅解析备份，不执行故事 HTML。

阅读器备份**没有包含 ECDICT 词典释义**，阅读笔记也不等同于释义，所以导入后可能有“待补释义”。可以手动编辑，或再次导入包含释义的 Excel / CSV 补齐。支持 ECDICT 的 `word`、`translation`、`definition`、`phonetic` 列名，但当前按整份表读取，有 50 MB 文件限制；请先筛出目标词再导入，避免将整本大型词典建成词书。

## 学习

阶段一按组序看词、释义、英文释义并可朗读；本组结束进入阶段二。阶段二随机排列不同中文释义，优先出四选一，答错显示正确释义，立即记录错误，点击继续进入下一词；本轮结束重测错词，直到全部正确。退出可从首页继续未完成的一轮。过关页可进入下一组。

阶段三支持复习已通过词，或按累计错误数倒序复习错词。它们也会重测本轮错词。累计错误数不会因答对清零。缺释义的词可以看词学习，但不会被当作有正确答案的选择题；整组仍会显示待补词数。可选“先回忆，再揭晓”。过关记录代表选择题通过，不代表永久记忆。

快捷键：当焦点不在按钮或输入框时，空格进入下一个／揭晓，数字 1–4 选择答案。

## 系统发音、离线和备份

使用 Web Speech API，默认优先设备的本地英语语音。设置里选择英音／美音声音及语速。声音由系统和浏览器提供，效果各设备不同；没有本地英语语音时断网可能无法发音。网络语音可能由系统服务联网处理朗读的词语。App 本身不上传词书和学习记录，也没有分析追踪脚本。

程序与依赖文件由 Service Worker 缓存在设备上，词书和进度由 IndexedDB 保存。第一次需联网打开 HTTPS 网址，缓存完成后可离线使用。清除网站数据、换浏览器、换域名或换设备均不会自动迁移记录，请使用设置 → 导出全部备份。恢复备份替换现有词书与记录；恢复后学习轮次从词书重新开始，但分组与历史学习记录保留。

更新代码时修改 `sw.js` 的 `CACHE` 版本号，再重新部署；新版本下载后重新打开页面。不要通过 `file://` 双击测试 PWA。开发可在文件夹用 `python -m http.server 8000`，打开 `http://localhost:8000/`。本工具作为全新 GitHub 项目交付，未自动创建或发布 GitHub 仓库。

## 代码与检查

`app.js`：界面、IndexedDB、学习；`core.js`：词条规范化、去重、累加、重测和备份；`importers.js`：表格读取与阅读器备份；`sw.js`：离线缓存。运行 `node --test tests/core.test.mjs` 可检查数据与学习逻辑。

原创程序使用 MIT 许可证。第三方依赖 JSZip 3.10.1 的 MIT 许可证随 `vendor/JSZip-LICENSE.md` 提供，XLSX 仅通过 JSZip 解压并读取必要的 XML，无 SheetJS / xlsx 依赖。示例词条与中文释义为本项目自编。导入资料的使用权由资料来源决定，程序许可不授予第三方词书版权。
